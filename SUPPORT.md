# Support

Foregather is maintained on a best-effort community basis, without a response-time
or production-support guarantee. Version 0.2 is experimental, especially live PAKE.

For usage questions and reproducible bugs, use
[GitHub issues](https://github.com/forgesworn/foregather-kit/issues).
Include the package version, platform, feature flags and a minimal synthetic
example. Never attach real invitation URLs, capabilities, words or private data.
For vulnerabilities, use [private reporting](SECURITY.md), not public issues.

Start with [the documentation index](docs/README.md). Applications remain
responsible for admission and deployment policy. See [validation](docs/validation.md)
and [the roadmap](docs/roadmap.md) for qualification still required.
