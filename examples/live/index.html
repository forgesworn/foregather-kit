About this demo

Pairings last two minutes, with one attempt per client. Character codes use 0–9 and A–Z excluding I, L, O and U. The public code finds a pairing; only the separate private secret can establish a connection.

Live pairing is experimental and unaudited. This demo transfers invitations; your app handles identity, room admission and consent.
